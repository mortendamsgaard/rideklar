# rideklar Redesign Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rebuild the rideklar interface so an iPhone 14 shows the arena and the current exercise's essential text with no scrolling, in a warm "stable" identity, with the shadcn and Tailwind layers removed.

**Architecture:** Presentation-only change. `app/globals.css` is rewritten below its section markers, `app/program-player.tsx` markup is restructured (animation and SVG logic untouched), `app/page.tsx` swaps the base-ui `Select` for a native `<select>`, and `app/layout.tsx` swaps Geist for Fraunces. The arena changes from width-driven to height-driven sizing so both 20×40 and 20×60 arenas fill the same vertical slot instead of letterboxing.

**Tech Stack:** vinext (Next.js-compatible app router on Vite), React 19, plain hand-written CSS, `lucide-react` icons, `node --test` with `--experimental-strip-types`.

**Spec:** `docs/superpowers/specs/2026-09-06-redesign-design.md`

## Global Constraints

- Target viewport: **390 × 664** CSS px (iPhone 14+ Safari visible area). All "no scrolling" claims measured against 664, not 844.
- Route colours are **fixed and semantic**: skridt `#25813b`, trav `#2365c7`, galop `#c63838`, neutral/parade `#62717c`. Never change these.
- Palette: sand `#faf4e9`, arena `#f2e4cc`, gold `#c98a2e`, leather `#b5722a`, ink `#3a2c1d`, surface `#fffdf8`, border `#e8dcc6` / `#e2d0b0`, muted `#6b5741`.
- The arena stays **portrait with A at the bottom**. Never rotate it.
- The 37 existing tests in `scripts/programs.test.ts` must pass **with their contents unmodified**.
- `app/program-player.tsx` must never contain the strings `LA1`, `LA4`, `la1-b`, `la4-b`, or `index === 10|15|22` — an existing test asserts this.
- Final dependency list must be exactly: `react`, `react-dom`, `react-server-dom-webpack`, `vinext`, `lucide-react`.
- UI text stays Danish.
- Commit after every task. Do not push until Task 8.

void test('no sage-palette colours remain in the stylesheet', () => {
  const css = read('app/globals.css');
  const allowed = new Set([
    '#faf4e9', '#f2e4cc', '#c98a2e', '#b5722a', '#8f5920', '#3a2c1d',

  const found = [
    ...new Set((css.match(/#[0-9a-fA-F]{3,8}/g) ?? []).map((h) => h.toLowerCase())),

});
